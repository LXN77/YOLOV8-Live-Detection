# Real-Time Object Detection with YOLOv8

This project demonstrates real-time object detection using the YOLOv8 model within a Google Colab environment. It integrates Python and JavaScript to access your webcam, process video frames, and display detection results live in your browser.

## 🚀 Features

- Real-time object detection via webcam
- Utilizes YOLOv8n model from Ultralytics
- Interactive HTML/JavaScript interface within Google Colab
- Start/Stop controls for live detection
